# Ralph Loop - правила автономной работы

## Как брать Issues

- Читай title, body и критерии готовности
- Проверяй что указанная ветка уже существует (если нет, создай)
- Работай только в этой ветке - не создавай новых

## Именоваяние коммитов

- По правилам в skill /git-commit

## Правила реализации

- Сначала тесты - потом реализация (TDD)
- После каждого финального изменения запускай тесты
- Если тесты красные после 5 попыток - остановись и напиши в Issue комментарий с описанием проблемы
- Если чувствуешь, что лимит turns скоро закончится, а Issue не закрыта - до его исчерпания напиши в Issue комментарий: что уже сделано, что осталось, и в каком состоянии код (например, красные тесты, незакоммиченные изменения)

## Правила завершения

- Убедись что все тесты зелёные
- Убедись что все требования выполнены
- Запусти skill /review для код ревью
- Закрой Issue
- Не создавай PR это сделает Stop Hook
